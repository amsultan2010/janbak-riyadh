# Security

Janbak is a static site with no accounts, no backend and no stored personal data, so the
attack surface is small. Reports are still welcome, for example:

- script injection through a data file, a query string or the page address
- a dependency with a known vulnerability that reaches the built site
- anything that sends a visitor's location somewhere it should not go
- a tampered or misleading link or phone number that looks deliberate

## How to report

Do not open a public issue. Use GitHub's private reporting instead:
[report a vulnerability](https://github.com/amsultan2010/janbak-riyadh/security/advisories/new).

Say what the problem is, where it is and how to reproduce it. You will get a reply within
7 days. This is a volunteer project with one maintainer, so there is no bounty.

## Supported versions

Only the current `main` branch, which is what the live site is built from.

## Not a security problem

A wrong phone number, wrong hours or a dead link is a data correction.
[Open one here](https://github.com/amsultan2010/janbak-riyadh/issues/new/choose).
